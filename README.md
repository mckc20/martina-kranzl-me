# Martina Kranzl

A personal photo diary and Blog built with Astro, local Markdown/MDX and Tailwind,
deployed on Vercel. Main sections: Home, Photos, Blog and About.

See [the publishing guide](docs/publishing.md) for adding content, image privacy,
drafts, scheduling, tags and deployment. Copyable examples live in `templates/`.
The [migration inventory](docs/migration.md) documents preserved legacy URLs.

```sh
npm install
npm run dev
npm test
npm run lint
npm run format:check
npm run build
```

MIT licensed; based on AstroPaper. Photographs remain attributed to their authors.
